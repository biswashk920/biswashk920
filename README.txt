# Biswash Kaphle

### 🌐 [**biswashk920.github.io**](https://biswashk920.github.io): my personal website, with research, publications and projects

---

Civil engineer from Nepal (B.Sc., Tribhuvan University, 2025; registered with the Nepal Engineering Council). My research is in hydrology and flood risk, mostly in Himalayan catchments, and lately I have been moving toward glacier and glacial lake hazards.

## Research

First author on:

- flood susceptibility mapping using deep learning, with Integrated Gradients for interpretation
- flash-flood susceptibility using morphometric analysis, SCS-CN and Snyder's synthetic unit hydrograph (under review)
- urban flooding and low-impact development under climate scenarios

Co-author on avalanche susceptibility mapping using GIS-based multi-criteria analysis (AHP), and on roadside drainage capacity assessment.

Full list on [Google Scholar](https://scholar.google.com/citations?user=VJNvHNoAAAAJ) and on the [website](https://biswashk920.github.io/#publications).

## Tools

Working knowledge of Python (including PyTorch), QGIS, Google Earth Engine, HEC-RAS, SWMM/PCSWMM and SWAT+. I am still learning to write cleaner, more reproducible code, and the repositories below are part of that practice.

## Projects

Notebooks and scripts, mostly on Nepal's Himalayan catchments.

### Live tools

- [Nepal Glacier Inventory & Hypsometry Explorer](https://biswashk920.github.io/nepal-glacier-explorer/) ([code](https://github.com/biswashk920/nepal-glacier-explorer)): glacier area and elevation distribution across Nepal from RGI 7.0, with an interactive map
- [PipeNet](https://biswashk920.github.io/water-supply-lab/) ([code](https://github.com/biswashk920/water-supply-lab)): water-supply pipe network solver checked against EPANET, with map-based node placement

### Flood and watershed analysis

- [Flood_In_KaliGandaki](https://github.com/biswashk920/Flood_In_KaliGandaki): flood and inundation risk mapping for the Kali Gandaki watershed using HAND (Height Above Nearest Drainage)
- [budi-gandaki-landslideFlood](https://github.com/biswashk920/budi-gandaki-landslideFlood): event-based analysis of the causes of the 11 October 2026 flooding in Budhi Gandaki
- [WaterShed_Screening_For_Hydropower_ROR](https://github.com/biswashk920/WaterShed_Screening_For_Hydropower_ROR): DEM-based screening of candidate run-of-river hydropower reaches, Kali Gandaki
- [watershed-delineation](https://github.com/biswashk920/watershed-delineation): watershed delineation with Google Earth Engine and WhiteboxTools; inputs are a rectangular DEM extent and an outlet point
- [WaterShed_Analysis](https://github.com/biswashk920/WaterShed_Analysis): watershed analysis notebooks
- [rainfall_analysis](https://github.com/biswashk920/rainfall_analysis): rainfall analysis notebooks
- [Frequency_Analysis](https://github.com/biswashk920/Frequency_Analysis): rainfall and discharge frequency analysis (Gumbel, Log-Pearson III, Log-Normal, GEV)
- [morphometric-pca-himalayan-basins](https://github.com/biswashk920/morphometric-pca-himalayan-basins): principal component analysis of morphometric parameters of a catchment
- [Temperature_Reconstruction](https://github.com/biswashk920/Temperature_Reconstruction): reconstructing temperature at a station from neighbouring stations using XGBoost

### Glaciers and glacial lakes

- [Tsho_Rolpa_GLOF](https://github.com/biswashk920/Tsho_Rolpa_GLOF): glacial lake outburst flood (GLOF) analysis for Tsho Rolpa
- [Glacial-Lakes-Detection-CNN](https://github.com/biswashk920/Glacial-Lakes-Detection-CNN): exploratory deep learning model for detecting glacial lakes. The results were not plausible, so this is unfinished and I am still working on it.
